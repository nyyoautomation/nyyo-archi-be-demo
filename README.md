# AI for architecture and engineering firms: live demo

No sign-up demo, fictional data only, replay mode (pre-recorded analyses).

- **English (international):** https://nyyoautomation.github.io/nyyo-archi-be-demo/

Three use cases:

1. **Methodology statement** for design competitions and design-services RFPs, structured on the scoring grid.
2. **Specification ↔ bill of quantities ↔ drawings check** before issuing tender documents.
3. **Site meeting minutes** from site-walk notes, cross-checked with the previous minutes and the programme.

Every result cites its source (document, page, clause), runs a contradiction check (confirm or dismiss each item) and shows a human-review banner. Live input checks, triage and Word export run in the browser.

Mobile-first layout: below 720 px every table is a stack of cards with flagged rows and collapsible sources; no page-level horizontal scroll at 360 or 390 px. From 720 px up, a table with a sticky first column.
